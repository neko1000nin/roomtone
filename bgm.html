03

Library

Library

各行の丸印がそのソースの所属ジャンルです。Moods で所属を編集、Disable で ローテーションから除外、自分で追加したもの（MINE）は Moods パネルの Delete で完全に削除できます。 編集内容はこのブラウザに保存され、Export で HTML に書き戻すためのコードが出ます。
なお 24時間ライブ配信は配信終了でIDごと消えます。再生に失敗したソースは自動でオフにして 次の候補に切り替え、7日後にもう一度試します（手動 Disable の方は期限なしで外れたままです）。

04

How to use

Adding, moving and removing sources

A. この画面から（手軽・このブラウザにだけ保存）

  1. By URL にYouTubeのURLを貼り、Add to library を押す。タイトルとチャンネルは自動取得を試みます。
  2. 入れたい気分のチップを選んで Add。以後その気分のローテーションに入ります。
  3. Library の各行の Edit で、タイトル・チャンネル・URL・種別・所属ジャンルを まとめて直せます。配信が終わってIDが変わったソースは、ここに新しいURLを貼れば復活します。
  4. 要らないソースは各行の Disable で気分のローテーションから外れます。自分で追加したものは Edit パネルの Delete で完全に消せます。まとめて戻すときは Enable all。
  5. 組み込みソースを編集すると EDITED と表示され、Edit パネルの Revert で HTMLに書かれた元の内容に戻せます。
  6. ここまでの変更はこのブラウザにしか残らないので、確定したら Library の Save to server を押す。サーバの sources.json に書き出され、 以後はどのブラウザで開いても同じ内容になります（未保存の変更があるとボタンが色付きに なります。書き込み先が無い環境では代わりにダウンロードされるので、bgm.html と 同じ場所に置けば同じことです）。

B. HTMLを直接編集（サーバに恒久的に残す）

  1. 末尾の CATALOG に1行足す。
    mykey : {t:'表示名', c:'チャンネル名', v:'動画ID11桁', k:'vod'},
  2. MOODS の入れたい気分の ids に 'mykey' を書き足す。複数の気分に入れて構いません。
  3. プレイリストを登録したいときは v の代わりに p:'PLxxxx…' を書きます。
  4. A でUIから足したものは Export でこの形のコードが出るので、それをそのまま貼れば恒久化できます。

ライブ配信より、数時間の通常動画（vod）の方が長生きします。海外レーベルのチャンネルは 日本から埋め込み再生できないことがあるので、迷ったら日本のチャンネルの長時間版が確実です。

# Room Tone

気分（ジャンル）を選ぶと、それに合った YouTube の長時間BGMが1本鳴る、一枚もののWebプレイヤー。

**Page:** https://neko1000nin.github.io/roomtone/

これは自宅サーバで動いている本体の**読み取り専用ミラー**です。外出先のスマホから
開けるように GitHub Pages で配信しています。

- スマホの Chrome でページを開き、メニューの「アプリをインストール」を選ぶと
  PWA としてホーム画面から全画面で起動できます
- ライブラリ（`sources.json`）は自宅側で編集され、変更があると自動で同期されます。
  このリポジトリへ直接コミットしても、次の同期で上書きされます
- ミラーには保存先（`/save`）が無いため、画面からの編集は保存されません（仕様）

再生には YouTube の埋め込みを使っています。ページ本体は HTML / CSS / JS を
1ファイルに内包し、ビルドも外部依存もありません。
